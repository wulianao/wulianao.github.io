# wulianao.github.io

这是为 wulianao 创建的个人静态网站，使用 GitHub Pages 托管。

站点地址（可能需要几分钟发布生效）：

https://wulianao.github.io

如何修改站点：

- 在此仓库的 `index.html` 和 `styles.css` 中编辑内容并提交即可，GitHub Pages 会自动更新。
- 若要替换头像，在 `index.html` 中的 `.avatar` 元素替换为 `<img>` 并把图片放入 `assets/` 目录。
- 若需要使用自定义域名，请在仓库根目录添加 `CNAME` 文件，内容为你的域名，并在域名 DNS 控制台添加对应的 GitHub Pages 记录。

如果你要我替换占位项目和联系方式，请把项目列表、邮箱和头像图片链接发给我，我会替你更新并推送。
